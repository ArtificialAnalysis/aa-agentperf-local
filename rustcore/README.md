# agentperf-local-rustcore

The optional Rust streaming client for
[agentperf-local](https://github.com/ArtificialAnalysis/aa-agentperf-local),
an open-source tool from [Artificial Analysis](https://artificialanalysis.ai).

Do not install this package directly. Install the extra instead:

```console
uv tool install 'agentperf-local[rust]'
```

It ships as source only, so installing it needs a
[Rust toolchain](https://rustup.rs). Both clients produce the same metrics.
