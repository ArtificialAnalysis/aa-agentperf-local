# RTX 5090 recipes

The RTX 5090 profiles come from NVIDIA's `local-ai-inference-recipes` at commit
`12b25c664d8bea9a819f6e6e33d59267dd7528df`. The catalog pins every checkpoint,
including external MTP and DFlash drafts, by Hugging Face commit, file size,
and SHA-256.

The measurements on this page were taken at a 131,072-token context. The
recipes now launch at 65,536 tokens.

## Long-context validation

The test used one 32 GB GeForce RTX 5090 with NVIDIA driver 595.91.07 and the
CUDA 12.8 llama.cpp b11026 build (commit `b49650adb`). Every server used a
131,072-token context, parallelism 1, and full CUDA offload. Each probe sent a
raw completion prompt of 32k, 64k, 96k, and 120k input tokens and asked for one
generated token. All four stages had to pass.

| Profile | Speculation | 120k elapsed | Peak process memory |
| --- | --- | ---: | ---: |
| `qwen35-9b-q4-k-m-mtp-rtx5090` | integrated MTP, depth 2 | 18.45 s | 13,652 MiB |
| `gemma4-26b-a4b-q4-k-m-mtp-rtx5090` | external MTP, depth 3 | 17.15 s | 22,254 MiB |
| `qwen36-27b-q4-k-m-mtp-rtx5090` | integrated MTP, depth 3 | 57.78 s | 27,416 MiB |
| `qwen38-27b-q4-k-m-mtp` | integrated MTP, depth 2 | 58.08 s | 27,266 MiB |
| `muse-glimmer-30b-q4-k-m-dflash-rtx5090` | external DFlash, depth 15 | 39.67 s | 21,574 MiB |
| `qwen36-35b-a3b-q4-k-m-mtp-rtx5090` | integrated MTP, depth 2 | 16.25 s | 26,408 MiB |
| `nemotron35-lightning-30b-a3b-q4-k-m-dflash-rtx5090` | external DFlash, depth 7 | 12.65 s | 28,940 MiB |

Each recipe allocates the 131,072-token single-sequence window and ingests a
120,000-token prompt with room for output on this card. The probe covers
context handling and inference only. It does not check chat templates, tool
calls, or reasoning extraction, so every profile keeps the admission state
`unqualified`.

To run one, put a CUDA llama.cpp b11026 build on `PATH` as `llama-server`.
